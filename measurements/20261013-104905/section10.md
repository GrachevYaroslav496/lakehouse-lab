# §10. Сводка результатов — sf1

Измерения выполнены последовательно. Размеры и число файлов относятся к исходным таблицам. Время записи измерено на временных копиях из tpch.sf1 с теми же форматом и кодеком; после проверки копии удалены.

Все времена — wall time процесса docker exec trino trino, включая запуск CLI; SET SESSION включён во время записи. DROP и проверка количества строк в время записи не входят.

Cold — первый запрос после перезапуска Trino и MinIO; warm — немедленный повтор. Перезапуск контейнеров не гарантирует очистку page cache ОС, поэтому cold здесь условный. Выполнена одна пара замеров для каждого варианта.
